AI Image Detector

Tool FrontEnd AI TypeScript React

Privacy-first browser tool that detects AI-generated images using gradient field PCA and frequency domain analysis — no uploads, no backend, no AI model required.

Gradient field PCA (Sobel + eigendecomposition) for anisotropy, coherence, and energy metrics.
2D FFT spectral analysis to identify diffusion model artefacts and compression patterns.
Viridis-palette gradient heatmap for visual inspection of suspicious regions.
Verdicts: REAL, AI-GENERATED, SUSPICIOUS, POSSIBLE AI, with per-metric breakdown.
