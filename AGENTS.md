# Site AGENTS

This repo is the public site and project catalog for Paulo R. Pereira Jr.

## What This Repo Is

* Static HTML, CSS, and browser JavaScript.
* No build step is required for the main site.
* Use this repo as the publication target for selected tools, studies, screenshots, and catalog updates.

## Editing Rules

* Keep paths relative and stable.
* Preserve metadata, social tags, canonical URLs, and accessibility helpers.
* Keep the site lightweight unless a change intentionally upgrades the implementation.
* Treat screenshots and generated assets as part of the published experience.

## Verification

* Open `index.html` in a browser for quick checks.
* For a local server, run `python3 -m http.server 8080` from this folder.
* Re-check the affected page after updating project cards, screenshots, or tag filters.

## Publication Notes

* Keep the catalog and screenshots aligned with the source repos.
* If a new public project or study is added, update the site copy and any related metadata together.
* Avoid changing external CDN dependencies unless the site is being intentionally modernized.
